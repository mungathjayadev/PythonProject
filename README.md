🧩 Sudoku Solver – Python Tkinter GUI

A simple and interactive Sudoku Solver built using Python and Tkinter.
This application allows users to input a Sudoku puzzle, solve it instantly using a backtracking algorithm, and reset the board anytime.

⸻

🚀 Features
	•	✔️ 9×9 Sudoku input grid
	•	✔️ Instant solving using a recursive backtracking algorithm
	•	✔️ Reset button to clear the board
	•	✔️ Error handling for unsolvable puzzles
	•	✔️ Clean Tkinter GUI

🧠 How It Works

The solver uses the backtracking algorithm, a depth-first search technique that attempts to fill each empty cell with valid numbers until the puzzle is solved.

Validation checks include:
	•	Row constraints
	•	Column constraints
	•	3×3 sub-grid (box) constraints
